# Code of Conduct / 行動規範

*English section is below the Japanese one.*

## 私たちの約束

このプロジェクト(Issue、Pull Request、その他のやり取りの場)に参加するすべての
人にとって、ハラスメントのない体験を提供することを目指します。年齢、体格、
障がいの有無、民族、性自認・性表現、経験レベル、国籍、外見、人種、宗教、
性的指向・性自認に関わらず、すべての参加者を尊重します。

## 望ましいふるまい

- 異なる意見・視点を尊重すること
- 建設的な批判を穏やかに伝え、また受け止めること
- コミュニティやツールにとって何が最善かを考えること
- 他の参加者に対して思いやりを持つこと

## 望ましくないふるまい

- 性的表現・言葉遣いや、望まれない性的な言い寄り
- 個人攻撃・侮辱的なコメント、荒らし行為
- 公然・私的を問わないハラスメント
- 本人の同意なく、他者の実名・連絡先等の個人情報を公開すること
- その他、プロフェッショナルな場にふさわしくないと合理的に判断される行為

## 適用範囲

この行動規範は、GitHub の Issue・Pull Request・コメント欄など、このプロジェクトの
公式なコミュニケーションの場すべてに適用されます。

## 運用体制についての注記

Uchinoko Reborn は本 fork のメンテナーが管理しています。上流の作者 pandrabox は
本 fork の対応担当ではありません。専任のモデレーション
チームは存在しないため、対応の即時性・一貫性については限界があることをご了承ください。
それでも、報告いただいた内容には誠実に対応します。

## 違反の報告

行動規範に反すると思われる行為を見かけた・受けた場合、公開してよい内容は
[本 fork の Issues](https://github.com/YukinoStuki2/Uchinoko-Reborn/issues) で報告できます。
Issues は公開です。個人情報や機密資料を投稿しないでください。
本 fork は専用の非公開受付窓口を現在設けていません。上流のオンライン報告サービスは
無効化されており、アプリ内の「問合せ」は本 fork の連絡先ではありません。

メンテナーは確認できた報告を公平に扱い、報告者のプライバシーと安全を尊重します。
即時の対応を保証するものではありません。

## English

### Our Pledge

We as participants in this project (issues, pull requests, and any other project
communication) pledge to make participation a harassment-free experience for
everyone, regardless of age, body size, visible or invisible disability, ethnicity,
gender identity and expression, level of experience, nationality, personal
appearance, race, religion, or sexual identity and orientation.

### Our Standards

Examples of behavior that contributes to a positive environment:

- Respecting differing opinions and viewpoints
- Giving and gracefully accepting constructive feedback
- Focusing on what is best for the community and the tool
- Showing empathy towards other participants

Examples of unacceptable behavior:

- Sexualized language or imagery, and unwelcome sexual attention
- Personal attacks, insulting or derogatory comments, and trolling
- Public or private harassment
- Publishing others' private information, such as a real name or contact
  details, without their explicit permission
- Other conduct which could reasonably be considered inappropriate in a
  professional setting

### Scope

This Code of Conduct applies within all official project communication spaces,
including GitHub issues, pull requests, and comment threads.

### A note on enforcement capacity

Uchinoko Reborn is managed by this fork's maintainers. Upstream author pandrabox
does not handle reports for this fork. There is no dedicated moderation team,
so response times and handling capacity are limited. Reports the maintainers
receive will be handled in good faith.

### Reporting

If you experience or witness behavior that violates this Code of Conduct,
information suitable for public disclosure may be reported through
[this fork's Issues](https://github.com/YukinoStuki2/Uchinoko-Reborn/issues).
Issues are public: do not post personal information or sensitive material.
There is currently no dedicated private reporting channel. The upstream online
report service is disabled; the in-app "Contact" button is not a reporting
channel for this fork.

Maintainers will review received reports fairly and respect reporters' privacy
and safety. Immediate responses are not guaranteed.
