# Reborn.2 validation coverage

The public regression suite covers Unity Editor reuse, owned bridge script
updates, preservation of local edits, bounded physics parameters, source-root
direction and conversion diagnostics. Unity integration uses a generated
humanoid fixture rather than a distributed avatar.

Detailed local model measurements are not part of the source distribution.
See [validation instructions](VALIDATION.md) and
[PhysBone preservation](PHYSBONE_PRESERVATION.md) for reproducible checks and
the distinction between offline verification and native gameplay.
