# Reborn.3 validation coverage

Regressions cover curved source spans, nested bone ownership, child components
following their selected parent, per-gender diagnostics, corrupt reports and
completion-message routing. A minimal geometric case reproduces a posture
comparison that incorrectly used one segment instead of the complete merged
span. The existing posture, weight and pivot thresholds remain enforced.

Detailed model exports and local measurements are not part of the source
distribution. See [tail-chain compatibility](TAIL_CHAIN_COMPATIBILITY.md) and
[validation instructions](VALIDATION.md). Tests do not establish visual physics
equivalence between Unity and Palworld.
