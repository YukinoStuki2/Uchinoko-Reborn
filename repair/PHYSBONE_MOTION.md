# 动态骨骼参数调节

Uchinoko Reborn 复用原有 PhysBone 列表、骨链分配和 KawaiiPhysics 输出。
在「实验室 → 摇摆详细设置」中，左侧勾选部件，点击该行「动态参数…」。

- **原有方式**：跟随主界面的全局软硬度；已有项目默认保持这个方式。
- **源参数适配**：复用现有 PhysBone `pull` / `spring` 测量映射，再加阻尼和有限摆角。
- **保守预设**：提高稳定性，减小摆角，适合先测试衣服或头发。
- **摆动幅度 25%–150%**：降低时减小摆角、增加运动阻力。增加幅度也不会突破源约束的兼容角度上限。
- **指定阻尼**：越大越快收敛；不勾选时由预设选择。
- **指定下垂力**：0 保持静止形状；负值施加向下作用，范围 -100 到 0。
  这些数值是 KawaiiPhysics 参数，不等于 VRChat 的 gravity / gravity falloff。

批量按钮只修改已勾选部件；不会悄悄启用原本关闭的骨链。每个部件都可以恢复原有方式。
修改后在主窗口重新转换，并在 Pal Avatar Manager 中重新导入、构建模型包，才会反映到游戏。
工具不会修改已经安装或上传的 MOD。

这不是 VRChat 物理解算器的完整移植：目前没有复制 PhysBone 碰撞器、抓取、参数曲线或
Hinge/Polar 平面约束。特殊约束显式勾选后使用小角度兼容近似；某些静止姿态无法安全转换时
仍会被安全检查排除。骨链容量仍受原有 9 个物理节点限制，调参数不会增加容量。
动态参数用于移动引起的摆动，不会自动添加环境风模拟。

数据经过同一条输出路径：GUI → `settings_lab_sway_chains.json` → job `sway_chain_overrides`
→ 最终有效骨链 `sway_node_overrides.json` → `sway_abp_build` → cooked KawaiiPhysics 字段。
旧设置没有 `motion` 时，此功能不更改原有参数。源参数适配和保守预设是需游戏测试的起点，
不能保证所有模型在 Palworld 中与 VRChat 完全一致。
